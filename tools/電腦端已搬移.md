# 電腦端元件已搬出本專案

GPT-SoVITS（語音）、本機生圖、文字推論等「需要電腦才能跑」的元件，已從本 Android Studio
專案搬到獨立資料夾，與 Android 程式碼完全分離：

```
~/VoiceWeaver-電腦端/
├── GPT-SoVITS/        後端程式碼 + 你的聲音模型 + pretrained_models
├── gpt-sovits-env/    conda Python 環境（torch / diffusers / transformers）
└── miniforge3/        conda
```

## 怎麼啟動電腦端
- 雙擊 `~/Downloads/VoiceWeaver語音中心.app`（已指向新位置；可用環境變數
  `SML_GS_HOME` 覆寫路徑）。
- 它會啟動控制中心(9890)、語音(9880)、生圖(9881)、文字推論(9882)，並自動 adb reverse。

## 手機怎麼連
有線 USB（自動 adb reverse）、無線 Wi-Fi（區網 IP）、或全域網 Tailscale（100.x，
官方下載 https://tailscale.com/download）。控制中心頁會即時顯示三種位址。

## 要重建 .dmg 時
`tools/dmg/build_dmg.sh` 仍可用；它從 `/tmp/vwdmg/payload` 與 `/tmp/vwdmg/gpt-sovits-env.tar.gz`
取材。重新整理 payload／重新 conda-pack 時，來源路徑改成 `~/VoiceWeaver-電腦端/`。

> Android app 本身不依賴這些檔案（透過 HTTP 連電腦），所以搬移不影響 App 編譯與執行。
