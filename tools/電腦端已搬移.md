# 電腦端元件已搬出本專案

GPT-SoVITS（語音）、本機生圖、文字推論等「需要電腦才能跑」的元件，已從本 Android Studio
專案搬到獨立資料夾，與 Android 程式碼完全分離：

```
~/Speak-My-Life-電腦端/
├── GPT-SoVITS/        後端程式碼 + 你的聲音模型 + pretrained_models
├── gpt-sovits-env/    conda Python 環境（torch / diffusers / transformers）
└── miniforge3/        conda
```

## 從 VoiceWeaver 升級（自動改名）
產品已全面更名為「拾語者 Speak My Life」（原名 VoiceWeaver）。舊資料夾 `~/VoiceWeaver-電腦端/`
會在第一次啟動新版語音中心或任一 `start_*.sh` 時自動改名成 `~/Speak-My-Life-電腦端/`：
- 只有舊的 → 改名，並在舊位置留一個捷徑（symlink／Windows junction）指向新資料夾——
  conda／miniforge 內寫死的舊路徑照樣能用，不必重裝。
- 新舊都有 → 用新的，舊的不動。
- 改名或留捷徑失敗 → 退回原狀，沿用舊路徑。
規則寫在 `tools/GPT-SoVITS/sml_migrate.py`（Python）與 `sml_migrate.sh`（啟動腳本）；
可用環境變數 `SML_GS_HOME` 指定別的位置（設了就完全不搬）。

## 怎麼啟動電腦端
- 雙擊 `Speak-My-Life語音中心.app`（`tools/dmg/build_dmg.sh` 打包；Windows 是 `Speak-My-Life語音中心.exe`）。
  舊的 `VoiceWeaver語音中心.app` 不會自動刪除，確認新版能用後可自行移除。
- 它會啟動控制中心(9890)、語音(9880)、生圖(9881)、文字推論(9882)，並自動 adb reverse。

## 手機怎麼連
有線 USB（自動 adb reverse）、無線 Wi-Fi（區網 IP）、或全域網 Tailscale（100.x，
官方下載 https://tailscale.com/download）。控制中心頁會即時顯示三種位址。

## 要重建 .dmg 時
`tools/dmg/build_dmg.sh` 仍可用；它從 `/tmp/smldmg/payload` 與 `/tmp/smldmg/gpt-sovits-env.tar.gz`
取材。重新整理 payload／重新 conda-pack 時，來源路徑是 `~/Speak-My-Life-電腦端/`，
payload 記得包含 `sml_migrate.py` 與 `sml_migrate.sh`。

> Android app 本身不依賴這些檔案（透過 HTTP 連電腦），所以搬移不影響 App 編譯與執行。
