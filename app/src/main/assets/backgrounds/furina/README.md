# Furina 背景圖片資料夾

App 啟動時會檢查這裡是否有 `bg.png`（或 `bg.jpg`），如有就把它複製到外部儲存區
並把 URI 寫進 `customBackgroundUri` 設定 — 不用手動匯入。

## 必要檔案

| 檔名 | 用途 |
|---|---|
| `bg.png` 或 `bg.jpg` | 主題背景圖（建議 1080×2400 或更高，深色基底以保證文字對比） |
| `splash.png`（選用）| 啟動畫面圖 |

## 版權注意

隨包附的圖片為**透明 1×1 占位 PNG**，App 啟動不會崩潰但畫面是空的。請依下列方式
替換為你自己合法取得的 Furina 圖片：

1. **官方授權商品**：HoYoverse 官方桌布、海報。
2. **官方推特/插畫**：個人非商用範圍內使用。
3. **二創**：CC 授權的 fan art（請尊重原作者）。

替換完成後**重啟 App**即可看到新背景。
